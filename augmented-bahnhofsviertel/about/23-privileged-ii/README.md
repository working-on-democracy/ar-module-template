## Beschreibung

Die AR-Installation PRIVILEGED von Jonathan Radetz versteht sich als ein Fenster in unterschiedliche Länder und Regionen. Betritt eine Reisende Person das Portal, so befindet sie sich in einer alltäglichen Szene aus einem anderen Land wieder. Ein schweifender Blick erkennt auf den verschiedensten Flächen in dieser Szenerie Schriftzüge mit subtilen Fakten zum statistischen Referenzalltag. Die Installation setzt sich zum Ziel, über eigene Privilegien nachzudenken und eine resultierend Verantwortung zu verstärken.
